WHY THIS MATTERS

森の持続可能性は、
炭素だけでは測れない。

森林は、気候、生物多様性、水、土、木材、地域の暮らしを同時に支えます。だからこそ、単一の制度や単一の数値だけで森林経営を説明することはできません。資金、人、情報を組み合わせ、長い時間軸で管理を続けられる仕組みが必要です。

このページは、「How Japanese forestry can become more sustainable?」（Notion資料）の内容を、日本語で読みやすく再構成したものです。

01 / BACKGROUND

森林資源はある。
管理を続ける基盤が課題になる。

日本の国土の約3分の2は森林です。戦後に造成された人工林は成長し、木材資源としての可能性を持つ一方、植えた後の間伐や再造林など、継続的な手入れを必要とします。

輸入材の増加によって国内林業の収益性が低下し、山村では人口減少と高齢化が進みました。所有境界や森林データが十分に整理されていない場所では、管理計画をつくり、実行し、結果を確かめること自体が難しくなります。

02 / POLICY INSTRUMENTS

4つの手段を、
組み合わせて使う。

市場の力、任意の基準、補助、法制度。それぞれに役割と限界があります。

01 / MARKET

J-クレジット

森林管理や植林による温室効果ガス吸収を、クレジットとして可視化します。

強み
資金を呼び込み、企業の気候行動と森林管理をつなげられる。
限界
炭素に焦点が偏りやすく、永続性・算定・価格の説明が欠かせない。
02 / VOLUNTARY

森林認証

FSCやPEFCなど、多様な関係者が責任ある森林管理を確認する仕組みです。

強み
市場アクセスと管理水準を高め、消費者への説明材料になる。
限界
取得・維持費がかかり、小規模所有者には負担になり得る。
03 / PUBLIC SUPPORT

間伐・再造林の支援

間伐や再造林を促し、森林の成長と吸収源としての機能を支えます。

強み
現場へ早く資金を届けやすく、参加の公平性を確保しやすい。
限界
成熟まで時間がかかり、労働力不足や樹種多様性の課題は残る。
04 / COMMAND

森林法・計画制度

国と自治体の計画、届出、許可などを通じて、森林利用を調整します。

強み
地域の計画と生産・保全の方向をそろえられる。
限界
行政の知識・人員・監視能力に左右され、運用コストも必要。

03 / EVALUATION

効果・効率・公平性で
制度を見直す。

評価は資料の論点を要約したものです。実際の制度設計では、森林の場所、所有形態、樹種、地域の担い手によって結果が変わります。

04 / ECONOMIC VALUE

経済価値は、
森が生む複数の便益から考える。

炭素の価格だけで森林の価値を表すと、管理を支える重要な便益を見落とします。

01

木材・地域産業

木材、食料、燃料などの資源を生み、伐採・加工・流通の仕事を支えます。

02

気候・炭素

吸収量や長期利用を確認し、企業の脱炭素投資と結びつけます。

03

水・土・防災

水源涵養、土壌保全、災害リスクの低減など、暮らしの基盤を支えます。

04

生物多様性・文化

生きもののすみか、景観、教育、レクリエーションなど、価格だけでは測りにくい価値があります。

投資の評価に必要なこと

森林の境界・樹種・成長量・炭素吸収・水質・施業履歴をGISなどで記録し、資金が現場の仕事と管理成果へ届いたかを継続的に確かめます。すべての価値を無理に貨幣化するのではなく、測れるものと説明すべきものを分けることが重要です。

05 / RECOMMENDATIONS

混ぜて、測って、
地域に戻す。

  1. 01

    4つの政策手段を組み合わせる

    J-クレジット、認証、支援制度、森林法を、森林の目的と地域の条件に合わせて使います。

  2. 02

    炭素以外の価値を計画に入れる

    生物多様性、水質、土壌、社会・経済面を管理計画と認証の評価項目に含め、定期的に確認します。

  3. 03

    小さな所有を束ね、コストを下げる

    森林組合、地域の協同管理、グループ認証などで、単独では重い計測・認証コストを分担します。

  4. 04

    民間資金を、現場の仕事へつなぐ

    資金を所有整理、森林整備、安全、人材育成、データ整備へ配分し、長期の地域雇用と管理能力を残します。
