## 仕様

| 項目 | 内容 |
|---|---|
| サイズ・印刷 | A4・両面カラー |
| 紙 | コート 90kg |
| 部数 | A / B / C 各 300 部(案ごとに 1 回ずつ注文) |
| 印刷費 | 1 案 7,172 円 × 3 = 21,516 円(税込、送料なし) |
| 表面 | 案ごとに変える(見出し・お悩み・QR) |

| QR | 案ごとに別(下の表)。独自ドメインが決まってから作る(#2) |

## 書き方の約束

- 計画書どおり、売却を前提にしないことを伝える。「何でも解決」「必ず売れる」「高く売れる」などの断定や、1 円物件のような価格の訴求はしない
- サイトと同じ言葉を使う: 無料相談 / 3 営業日以内にご連絡 / 全国からご相談いただけます / 山の場所が曖昧でも構いません
- 電話番号は載せない(2026-10-28 決定)。連絡先は QR(フォーム)と、できれば専用メール(#3)
- 共有画像・写真は、サイトで使っている自社の写真から選ぶ

```

今のうちに整理しませんか。

分かる範囲から、ご家族と一緒に確認できます。

こんなことはありませんか
・親の山がどこにあるのか、はっきり分からない
・名義が祖父母のまま、共有者が何人もいる
・相続したあと、子どもに負担を残したくない

[QR] 無料相談はこちら
     スマートフォンで読み取ると、申し込みフォームが開きます

さとやま不動産 ― 山林・里山の管理と出口整理
```

```
・倒木や越境で、近所に迷惑をかけていないか心配
・管理にいくらかかるのか分からない

[QR] 無料相談はこちら
     スマートフォンで読み取ると、申し込みフォームが開きます

さとやま不動産 ― 山林・里山の管理と出口整理
```

## 表面 C「複合資産」

- 主な対象: 山林と一緒に農地・空き家を持つ方、農林家、ご家族
- QR の飛び先: お悩みから探すの「費用の負担」(`?src=flyer-c#costs`)。山林と一緒に空き家・農地を引き継いだ方の項目がここにある

```
森林・耕作放棄地・空き家。

まとめてご相談ください。

こんなことはありませんか
・山林・農地・空き家を、まとめて引き継いだ
・どこに相談すればよいのか、土地ごとに違って分からない
・固定資産税や管理費が、ずっとかかるのが心配
```
