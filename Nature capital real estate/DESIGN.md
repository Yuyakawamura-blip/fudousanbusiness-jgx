## 3. 01 コンセプト(案)

**一言で:** 山林・里山を持て余している人が、「売る/持ち続ける/管理を頼む/手放す」を決める前に、状況を一緒に整理してくれる相談先を見つけ、申し込めるサイト。

- 主対象: 山林・里山の所有者と相続予定者(遠方在住・高齢・家族)【決定:2026-10-21】
- 副対象: 林業事業体(ツール)/企業・個人(企業の森・クレジット・体験)【決定】
- 困る場面【仮説】
  1. 相続で山を引き継いだが、場所・境界・価値が分からない
  2. 遠方で手入れできず、倒木・越境・税金が気になる
  3. 手放したいが、売れるのか・誰に頼めばよいか分からない
- 減らしたい負担: 相談先を探して何か所も断られる手間と、「価値がない」とあきらめて放置すること
- 対象外: 山を買いたい人向けの物件サイト、1 円物件のような価格の訴求(計画書 2.3 の方針)【決定】

計画書とずれている点(判断が要る)

- 【決定:2026-10-28】**B2B・B2G の扱い** — 計画書は「自治体・都市企業を先に取る」(2.4)が、サイトは所有者の相談窓口を主役のままにする。自治体・士業・金融機関は私たちについての「ご紹介・連携」の節で受け、主な説明は直接の訪問で行う
- 【決定:2026-10-28】**対応地域** — **全国**(相談は全国から、現地確認は地域の事業者との連携状況により個別に案内)。計画書は札幌・北海道+東京だが、入口を地域で絞らない。一度「現地は北海道中心」と書いたが、同日にユーザーの判断で全国に戻した。施業できない地域を約束しない書き方は維持
- 【決定:2026-10-28】**空き家・農地・遊休地(B ライン)** — 山林と一緒の場合のみ受け付ける。山林が主役のまま、チラシ C 案(複合資産)の受け皿にする。→【決定:2026-10-29 変更】空き家・農地だけの相談も、まずは引き受けて話を聞く(貴重な課題として集める)。その後の扱いは件数を見て考える。サイトはさとやま不動産 Q&A の一文だけ変更

## 4. 02 仕様(5 層)

### 戦略
- 誰の何を: §3 のとおり
- 成功: 有効相談数、流入元別の面談化率と相談獲得費【決定】。「有効相談」= フォームが届き、本人と連絡がつき、対象(山林等)で、**初回インタビューの日程が決まったもの**【決定:2026-10-28】。営業・いたずら・対象外は除く。空き家・農地だけの相談も、日程が決まれば有効相談に含める【決定:2026-10-29】。集計は「フォーム送信数 → 有効相談数」を流入元ごとに並べ、その比を面談化率とする

### 要件(優先度順)
| 優先 | 必要な機能・情報 | 状態 |
|---|---|---|
| 必須 | 悩みから入れる入口(トップ・お悩み) | 【実装済み】 |
| 必須 | サービス内容・流れと費用(無料の範囲)・Q&A | 【実装済み】 |
| 必須 | 運営者(日本GXグループ)と対応地域 | 【実装済み】(全国。現地は個別) |
| 必須 | 相談フォームと流入元の記録 | フォームは【実装済み】、記録は作業中 |
| 必須 | 相談後に何が起きるか(誰から・いつ連絡が来るか、何を渡すか) | 連絡の目安・整理メモとも【実装済み】(流れ 01・02) |
| 中 | 空き家・農地・遊休地 | **山林と一緒なら受け付ける**【決定:2026-10-28】。空き家・農地だけでもまず引き受ける【決定:2026-10-29】。お悩み(B 費用の負担)とさとやま不動産 Q&A に 1 項目ずつ【実装済み:ローカル確認のみ】 |
| 高 | フォーム以外の連絡手段 | **専用メールをフォームと並べて載せる**【決定:2026-10-28】。電話は載せない。アドレス待ち。公開はアドレスができてから |
| 中 | 副対象への入口(林業事業体・企業) | 【実装済み】 |
| 中 | 信頼形成(計画書 7.2) | さとやま不動産「私たちの考え方」に「不利なことも先に伝える」「引き受け手は隣接者・地域事業者も含める」を追加【実装済み:ローカル確認、2026-10-28】。利益相反の説明は自社で媒介・買取を始めるときに検討 |
| 中 | 自治体・士業・金融機関向け | 私たちについてに「ご紹介・連携」の節(`#referral`)【決定・実装済み:2026-10-28、ローカル確認のみ】。ヘッダーは変えない。紹介元ごとの QR は `?src=partner-名前` |
| 低 | 事例 | 実績ができてから【決定:2026-10-22】 |

### 構造(相談までの流れ)
```
知る(チラシ QR / SNS / 紹介 / 検索)
  → 入口ページ(トップ or さとやま不動産。QR は訴求に合うページへ)
  → 自分の悩みがあるか確認 → 流れと費用(無料の範囲)を確認
  → 相談フォーム(流入元は自動入力) → 送信完了
  → 担当から連絡 → 初回インタビュー(無料)
```
失敗時の戻り方【決定:2026-10-29】
- フォームの入力が難しい(高齢・スマホ不慣れ)→ 専用メールで受け付ける(アドレス待ち)。メールで来た相談の流入元は初回連絡で「何で知ったか」を聞いて記録する
- 送信したが連絡が来ない → 「3 営業日以内に担当者から連絡」をトップと さとやま不動産 の流れ 01・相談ボタン付近に記載【実装済み:ローカル確認のみ】
- 対象外の相談(山林以外・対応地域外)→ 空き家・農地だけでもまず引き受けて話を聞き、その後どうするか考える【決定:2026-10-29】

## 6. 08 デザイン精緻化(2026-10-29〜)

品質目標: FWA・The Webby Awards・Awwwards などで受賞を目指せる水準(ガイド改訂版 7 章の 5 観点でレビューする)。主役は高齢の山林所有者なので、読みやすさは落とさない。

- 【事実】v1 のムードボード(見本 3 案)は「AI で作った感」があり不採用。原因の自己評価: 定番の型のまま / 色が事業の実物から来ていない / 自動生成の飾り / 写真が手持ちの 2 枚だけ(`maintenance/moodboard/v1/`)
- 【決定:2026-10-29】ムードボード v2 は実在のサイト 7 つから作成(`maintenance/moodboard/`、参考画面は社外のものなのでリポジトリに入れない)
- 【決定:2026-10-29】世界観の軸は **「実物を主役に」+「人の言葉」**。公図・登記簿・森林簿・納税通知書など相談の場に出てくる紙を主役にし、悩みは相談者の言葉で語る
- 【決定:2026-10-29】素材は公開資料をもとに見本の書類を作り、撮影する(撮影リスト: `maintenance/photo-shotlist.md`)。個人名・地番は架空にし「見本」と分かるようにする
- 【決定:2026-10-29】骨格(ワイヤーフレーム `maintenance/wireframe/`): 相談者の言葉の見出し + 相談の机 → よくある最初のひと言 6 つ → 相談の机に出てくる 4 枚の紙 → 流れと費用(整理メモの見本付き)→ 売却を前提にしない → その他の方へ → 相談
- 【仮説】デザインシステム「書類の文法」(試作 v1 `maintenance/prototype/`): 色は紙・墨・鉛筆・朱肉の朱(相談と「無料」の印)・藍(書き込み)。緑は写真の中だけ。書体は BIZ UD 明朝(見出し・人の言葉)+ BIZ UD ゴシック 18px(本文)。罫線の欄・番号・朱の丸印を部品にする
- 見本の書類(架空、撮影の小道具を兼ねる): `maintenance/samples/`
- 自己レビュー 1 回目で直したこと: 最初の画面の書類が小さく「スクリーンショットを並べただけ」→ 公図を大きく、朱の区画に藍の書き込み / 4 枚の紙の下半分の空白 → 上部だけ切り出し / 見出しの数字の前後で改行
- 【事実】試作 v1 もユーザー評価は「まだ AI っぽい」(組み方・素材が作り物・細部の定番表現・言葉づかいの 4 点すべて)。原因: 素材と言葉が想像で作ったもの / 型の組み合わせで構造を作っている
- 【決定:2026-10-29】構造の発想が違う案を先に比べる(`maintenance/structure/`: 1 一枚の地図 / 2 手紙 / 3 相談票)。傾けた紙・影・丸い印・番号付き小見出し・「―」・整いすぎた優しい文は使わない。実際の写真と所有者の実際の言葉は後で入れる
- 【決定:2026-10-29】トップの構造は「手紙 → 相談票」(試作 v2 `maintenance/prototype/v2.html`)。手紙で誰が何をするかを伝え、相談票で自分の場合を確かめて申し込みへ。相談票の内容はブラウザの中だけで、送信しない(フォームへの転記は今後検討)
- 【決定:2026-10-29】チラシは 表 = 案ごとの短い手紙(計画書の A/B/C の見出しはそのまま)/ 裏 = ペンで印を付ける相談票と費用の表。HTML で作り Chrome で PDF に書き出す(Figma は使わない。ガイド改訂版 7 章)
- 【実装済み:2026-10-29】トップの本文を「手紙 → 相談票 → 費用」に差し替え(ローカルで確認)。写真はフリー素材(CC BY 2.0、クレジット表記)。他のページはまだ旧デザインのため、トップだけ書体と雰囲気が違う
